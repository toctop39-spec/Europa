# EUROPA STRATEGY ONLINE

Браузерная геополитическая стратегия: флаги-армии, 1 день = 2 секунды, документы, экономика, договоры.
Теперь — **онлайн**: много игроков в одном мире, у каждого своя страна, остальные страны ведёт ИИ.

## Как это работает
Сервер раз в 2 секунды рассылает всем «тик» с командами игроков. Каждый браузер считает мир сам
(детерминированно, один seed), поэтому все видят одно и то же. Новый игрок «догоняет» мир по журналу
команд (на экране «Синхронизация»). Сервер сверяет контрольные суммы и сообщает о рассинхроне.

Работают: вход по имени и выбору страны, договоры (торговля, ненападение, союз, культурный обмен, свой текст)
между игроками и с ИИ, кредиты, мирные договоры и пересмотр границ, капитуляция (победитель-игрок сам
выбирает условия), объявление войны, общий и личный чат, смена флага, покинуть страну (её берёт ИИ).
Предложения другому игроку приходят ему в «Канцелярию»; предложения ИИ он решает сам в течение нескольких дней.

## Запуск на Render.com через GitHub
1. Создайте на github.com новый репозиторий (например `europa-online`) и загрузите в него **всё содержимое этой папки**
   (кнопка *Add file → Upload files*, перетащите файлы и папки; `node_modules` не нужен).
2. На https://render.com: **New → Blueprint** (или **New → Web Service**) → подключите GitHub → выберите репозиторий.
   - Blueprint: Render сам прочитает `render.yaml`.
   - Web Service вручную: Runtime **Node**, Build Command `npm install --omit=dev`, Start Command `npm start`, Health Check Path `/healthz`.
3. Дождитесь деплоя и откройте выданный адрес `https://....onrender.com`. Отправьте ссылку друзьям.

### Важно про бесплатный тариф
- Бесплатный сервис **засыпает через ~15 минут без посетителей** и просыпается около минуты. Мир на паузе, пока нет игроков онлайн.
- Бесплатный диск **не сохраняется**: при перезапуске/новом деплое мир начнётся заново (игроки снова выберут страны).
- Чтобы мир жил между перезапусками: платный план + Disk (Settings → Disks, mount path `/var/data`) и переменная
  `DATA_DIR=/var/data`. Сервер сохраняет мир каждые 30 секунд и при остановке.

### Настройки (переменные окружения)
| Переменная | По умолчанию | Смысл |
|---|---|---|
| `DIFFICULTY` | `1` | сложность ИИ: `0.6` лёгкая, `1` нормальная, `1.35` жёсткая (только до создания мира) |
| `DATA_DIR` | — | папка для сохранения мира (`world.json`) |
| `MAX_PLAYERS` | `40` | максимум игроков |
| `PORT` | задаёт Render | порт |

Сбросить мир: удалите `world.json` в `DATA_DIR` и перезапустите сервис.

## Локально
```
npm install
npm start            # http://localhost:3000
npm test             # автотест: сервер + 3 клиента (нужны devDependencies)
```
Одиночный режим без сервера: откройте `public/index.html` или добавьте `?solo=1` к адресу.

## Заметки
- Играйте в браузерах одного семейства (Chrome/Edge/Firefox актуальных версий). Если появится красная плашка
  «Рассинхронизация» — нажмите «Пересинхронизироваться».
- Чем дольше идёт мир, тем дольше «догоняет» новый игрок (~1 час мира ≈ минута загрузки).
- `public/js/grid.js` — готовая карта владения (создаётся `npm run build:grid`, нужен `npm install` с devDependencies).
